# Personal Trainer — учебный frontend

Рабочий React + TypeScript + Vite-проект с клиентами, тренировками, календарём, CSV и статистикой длительности. По умолчанию работает локальный деморежим: 4 клиента, 6 тренировок на 5–12 октября 2026, 305 минут. Изменения сохраняются в `localStorage` этого браузера.

В исходном задании требуется React-интерфейс для клиентов и тренировок. Условия официальных Part 1–4 отсутствуют. Этот комплект реализует согласованное самостоятельное дополнение задания: этапы A–D; они не являются официальными частями курса и не гарантируют оценку.

## Запуск на Mac

Скопируйте папку проекта в `<локальный-путь>`. В этой папке должны лежать `package.json` и `package-lock.json`, а не ещё одна вложенная папка `personal-trainer`.

```bash
cd <папка-этого-репозитория>
node --version
npm ci
npm run dev
```

Node: минимум 22.12.0; комплект проверен на Node 24.21.0. Откройте URL из терминала (обычно `http://127.0.0.1:5173`). Для работы демо внешний API и `.env` не нужны. `Ctrl+C` останавливает сервер. Не открывайте `index.html` двойным щелчком.

## Что работает

- Клиенты: все контакты и адреса, поиск по полям, сортировка, создание, редактирование, подтверждаемое удаление вместе с тренировками.
- Тренировки: клиент и время, поиск/сортировка, создание и подтверждаемое удаление.
- Календарь: месяц или неделя, переход периода, «Сегодня», открытие карточки занятия.
- CSV: текущий отфильтрованный список клиентов, UTF-8 BOM, экранирование кавычек и защита от формул.
- Статистика: сумма минут и количество тренировок по активности; включает все даты.
- Состояния загрузки, ошибок, пустого списка, повторная загрузка, проверка полей и доступные диалоги.

## Живой API: включать осознанно

При необходимости скопируйте `.env.example` в `.env.local`, установите `VITE_ENABLE_LIVE_API=true` и перезапустите Vite. После запуска приложение всё равно начинает с демо. Выберите кнопку «API» и подтвердите подключение.

Это общая база преподавателя. Любое добавление, редактирование или удаление изменяет чужое общее состояние и требует отдельного подтверждения. Удаление клиента удаляет его тренировки. В проекте нет вызова reset API. Для практики CRUD используйте демо. Реальные POST/PUT/DELETE в ходе подготовки комплекта не проверялись; сетевые изменения проверены с моками.

Адрес задаётся через `VITE_API_BASE_URL`. Переменные Vite доступны в браузере: не храните в них секреты. Источник данных виден в бейдже. Переход между режимами не переносит данные из локального демо в API.

## Проверки

```bash
npm run typecheck
npm test
npm run build
npm run preview
npm run docs:check
```

`preview` показывает собранную версию (обычно порт 4173). При другом origin/порте браузер использует отдельное локальное хранилище. Автоматические тесты используют jsdom и моки, а не общую базу преподавателя.
