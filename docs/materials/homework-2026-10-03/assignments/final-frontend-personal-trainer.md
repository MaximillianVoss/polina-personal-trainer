# Frontend Programming — Final task: Personal Trainer

Источник: `sources/final_tasks.pdf`, страница 3.

## Исходное описание

Personal Trainer company needs front end app for their customer database. Database contains info about customers and their trainings. They have REST API and documentation that contains all information needed for front end development. Your task is to implement front end for them using React.

REST API documentation: https://juhahinkula.github.io/personaltrainerdocs/

What to do if there is no data in the database? You can find the instructions from the REST API document.

## Оценивание

The grade of the final task depends on how far you go (Part 1–4). Requirement for passing is at least Part 1 completion. Each section describes what is required to complete the section.

Дополнительно оцениваются:

- качество кода: логичные имена, модульность, форматирование;
- интуитивный интерфейс;
- для оценки 5 необходима своевременная сдача.

## Чего нет в архиве

**Условия Part 1, Part 2, Part 3 и Part 4 отсутствуют.** Нельзя приписывать им таблицы, календарь, диаграммы, экспорт или конкретные CRUD-операции без исходных условий.

По текущему поручению пользователя реализован полный самостоятельный вариант: CRUD клиентов, просмотр/создание/удаление тренировок, поиск и сортировка, календарь, статистика и CSV. Он работает локально без внешнего сервера; подключение учебного REST API включается отдельно. Это предложенный нами объём, а не восстановленные или подтверждённые требования Part 1–4. После получения этих частей нужно сверить критерии с готовым приложением.
