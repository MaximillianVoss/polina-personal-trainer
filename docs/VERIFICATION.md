## Что покрывают тесты

- Клиентские поля, обязательность, email, целая длительность, связь с существующим клиентом.
- ISO/местное время, невозможные даты, високосный год, 42 дня месяца и 7 дней недели, переход года.
- Поиск/сортировка без изменения исходного массива, суммы минут.
- Экранирование CSV, UTF-8 BOM, CRLF, защита от формул и опасных пробельных префиксов.
- Детерминированное демо, сохранение и редактирование после повторного чтения, тренировки, каскадное удаление, отказ при повреждённых данных и явное восстановление.
- HAL-клиенты/тренировки и обычный массив `/gettrainings`, отсутствующая связь, 204 и пустой ответ, HTTP/JSON-ошибка, доверенный origin, ресурсные URL, next-пагинация.
- Интерфейс: CRUD через форму, сообщения ошибок, фокус, Escape, отмена удаления, создание/удаление занятия через календарь, неделя, статистика, сортировка, повторная загрузка.
- Демо не вызывает сеть; отмена подключения или подтверждения записи API не отправляет POST/PUT/DELETE.

## Ограничение проверки живого API

Изучены официальные страницы [Customers](https://juhahinkula.github.io/personaltrainerdocs/customers/) и [Trainings](https://juhahinkula.github.io/personaltrainerdocs/trainings/). Выполнены только read-only GET-запросы к текущему base URL. Структура: `/customers` — HAL с 16 элементами; `/trainings` — HAL с 10; `/gettrainings` — массив с 10 и вложенным клиентом. Это временный снимок количества, не ожидаемое постоянное число.

Имена и контакты живой общей базы не сохранены в комплект. POST, PUT, DELETE, reset не выполнялись. Payload и обработка результатов записи проверены с моками. Реальный браузерный CORS и успешная запись в общий сервис не подтверждены. Демо полностью исполняет эти операции локально.

## Что остаётся неизвестным

Точные критерии Part 1–4, официальная градация оценки, срок/канал сдачи, состояние сервиса в момент запуска на Mac. Репозиторий GitHub и дневник ученицы не создавались. Локальное тестирование и документация не являются публикацией или официальной приёмкой преподавателем.
